# go_snowflake_ruby

Ruby binding over the Snowflake Go driver.

## Shared engineering context

Singlespot-wide engineering conventions live in the
[tech-context](https://github.com/Singlespot/tech-context) repo, cloned as a
sibling of this one. A SessionStart hook
(`.claude/hooks/load-shared-context.sh`) loads its index, `CONTEXT.md`, into
every session, and warns with the clone command when the repo is not cloned.
